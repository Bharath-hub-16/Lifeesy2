# Lifessy Corp website

A responsive, animated React + TypeScript website built with Vite, Tailwind CSS, Framer Motion, and Lucide React. The month-wise rewards, products, participation details, and terms are transcribed from the supplied Lifessy 24-Month Lucky brochure.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and serve the `dist/` directory.

The website is informational. It does not collect registrations or payments.
